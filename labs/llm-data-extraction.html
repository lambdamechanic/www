Arachnomancer: LLM-assisted data extraction

Arachnomancer is an experiment in using LLMs to help turn a seed URL and a description of the desired data into a scraper. The aim is to use a model to discover structure, then capture that structure in deterministic selectors that can be inspected and tested.

The approach

  • Find candidate pages. Explore links from the seed site and distinguish navigation from pages containing the desired items.
  • Isolate useful content. Remove shared boilerplate and ask an LLM to propose fields and example values.
  • Generate and check selectors. Derive XPath or JSON selectors from those examples and validate the extracted data.

The engineering question

Where does an LLM help with an unfamiliar site, and where is ordinary code easier to trust? This experiment explores that boundary, along with caching, repeatable runs and tests for extraction behaviour.

The related Shake pipeline experiment looks at dependency tracking for this kind of workflow.
