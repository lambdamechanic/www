Tooltest: because agents deserve good tools too

My property-based and fuzz testing tool for Model Context Protocol (MCP) servers checks the contracts tools advertise. It finds valid inputs a server rejects, outputs that don’t match their schemas, and failures in stateful tool sequences.

Coding agents can be surprisingly good at working around a broken tool. Tooltest gives them a smaller, reproducible failure to diagnose instead.
