Shake-based LLM pipelines

ShakingSpider explores using Shake, a Haskell build system, to orchestrate fetching and LLM page classification for an Arachnomancer-style crawler. Fetched pages and cached classifications become files whose dependencies can be tracked, much like source files and build artefacts.

Why a build system?

  • Selective recomputation. Change an input and rerun the steps that depend on it, keeping unrelated work cached.
  • Parallel work. Run independent steps concurrently while respecting dependencies.
  • Inspectable artefacts. Store fetched pages and classifications so intermediate results can be inspected and compared.

The engineering question

LLM calls are expensive enough that rerunning an entire pipeline makes experimentation painful. This is an exploration of how much ordinary build-system machinery can help with that problem. Caching a model’s output makes it reusable; it does not make the model deterministic.
