Shake-Based LLM Pipeline Framework

We are adapting the Shake build system to drive file-focused recomputation for LLM-dependent workflow stages.

By treating every prompt, retrieval, and post-processing step as a dependency-aware target, the framework unlocks parallel execution and avoids re-running expensive calls that have not changed.

Capabilities

  • Deterministic dependency graph. Shake gives us a programmatic view of which artifacts depend on which prompts, so we never chase hidden state.
  • Fast experiment loops. Engineers tweak a prompt or model, rerun the build, and see only the relevant stages recompute.
  • Cost control. Cached outputs keep API usage predictable, and the system flags long dependency chains that would trigger full rebuilds.

Next steps

We are packaging the framework for teams running large evaluation suites or agent fleets that need reliable, low-latency refreshes.
