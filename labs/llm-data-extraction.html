Arachnomancer: LLM-assisted data extraction

Arachnomancer uses LLMs to discover the structure of unfamiliar websites and generate deterministic, testable scrapers. Starting from a seed URL and a description of the desired data, it uses models for discovery and inference, then captures the results as ordinary code. That code uses deterministic selectors and can be tested and maintained without asking a model to interpret every page.

The approach

  • Find candidate pages. Explore links from the seed site and distinguish navigation from pages containing the desired items.
  • Isolate useful content. Remove shared boilerplate and ask an LLM to propose fields and example values.
  • Generate and check selectors. Derive XPath or JSON selectors from those examples and validate the extracted data.

The engineering question

Where does an LLM help with an unfamiliar site, and where is ordinary code easier to trust? I use Arachnomancer to explore that boundary, along with caching, repeatable runs and tests for extraction behaviour.

The related Shake pipeline experiment looks at dependency tracking for this kind of workflow.
